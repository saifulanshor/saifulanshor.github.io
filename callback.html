What to do next / Langkah berikutnya

  1. Salin URL lengkap dari address bar browser ini (yang berisi ?code=…&state=…).
  2. Tempel URL itu ke prompt oauth_helper.py tiktok di terminal, saat diminta "paste the FULL URL you were redirected to".
  3. Setelah itu tab ini bisa ditutup. Kode ini hanya berlaku sekali dan sebentar — jangan dibagikan ke siapa pun.

Privacy / Privasi

Halaman ini hanya membaca parameter di URL di browser kamu sendiri. Kode tidak dikirim atau disimpan di mana pun oleh halaman ini.

Callback TikTok (ringkas)

Halaman ini hanya dipakai sebagai tujuan redirect setelah login TikTok untuk Faceless Upload. Kalau kamu membuka halaman ini langsung tanpa login TikTok, tidak ada yang perlu dilakukan.
